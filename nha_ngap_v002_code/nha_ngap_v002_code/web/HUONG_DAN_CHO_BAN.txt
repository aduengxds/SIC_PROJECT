-----------------------------------------------------------------------

  [ ] Windows 10 hoac 11, ban 64-bit.
  [ ] GPU NVIDIA (da kiem chung tren RTX 2050; RTX 30xx / 40xx chay
      tot hon). Khong co GPU van chay duoc, xem muc 6.
  [ ] Python 3.13 ban 64-bit, tai tu https://www.python.org/downloads/
        - PHAI la ban 3.13. Goi cai dat cua du an co san ban dung cho
          Python 3.13; Python 3.12 hay 3.14 deu KHONG cai duoc.
        - Khi cai nho tich "Add python.exe to PATH".
        - DUNG ban Python tren Microsoft Store: ban do khong co lenh
          "py" ma file CAI_DAT.bat can dung.
  [ ] Driver NVIDIA moi: ban CUDA 13.2 cua du an can driver R580 tro
      len. Vao NVIDIA App hoac geforce.com cap nhat cho chac.
  [ ] Trong o dia ~6-7 GB.
  [ ] Mang Internet cho lan cai dau tien (tai khoang 2,5 GB).

3. BUOC 2 — BAM CAI_DAT.bat (10-30 phut)
-----------------------------------------------------------------------

Bam dup vao CAI_DAT.bat va de yen. No se:

    - Tao mot moi truong Python rieng trong thu muc "venv".
    - Tai torch + torchvision ban CUDA (~1,9 GB) tu pytorch.org.
    - Tai mmcv (wheel dung cho Windows / Python 3.13 / CUDA 13.2) tu
      GitHub.
    - Tai mmdet, mmengine, FastAPI, uvicorn, pillow.
    - Chay luon cong kiem tra moi truong o cuoi.

Lan dau mat 10-30 phut tuy mang. Thay chu [n/6] nhay dan la binh
thuong, khong phai treo.

Neu giua chung loi mang: cu bam lai CAI_DAT.bat. No tu bo qua cac buoc
da xong, khong tai lai tu dau.

Cuoi buoc nay, neu ban thay dong:

    CA X BUOC XANH.

la moi thu da san sang. (Con mot dong nho sai chinh ta o cuoi — "CA 5
BUOC XANH" trong khi that ra co 6 buoc — chi la cau chu, khong phai
loi gi.)

CAI_DAT.bat cung chay san cong kiem tra lan dau, mat khoang 1 phut.

-----------------------------------------------------------------------
4. BUOC 3 — BAM CHAY_WEB.bat
-----------------------------------------------------------------------

Bam dup vao CHAY_WEB.bat. Cho 10-25 giay de nap model, roi trinh duyet
tu mo dia chi http://127.0.0.1:8000

Lan dau tien Windows Defender se hien hop thoai "Windows Security
Alert" hoi co cho phep khong — bam Allow access. Neu lo bam Cancel thi
web van chay binh thuong tren may ban, chi la may khac trong cung
mang Wi-Fi khong vao duoc. Trong file CHAY_WEB.bat co san cach them
quy tac tuong lua bang tay (phan ghi chu o cuoi file).

Muon tat web: bam Ctrl+C trong cua so den, hoac dong cua so do lai.

Vai tuy chon, go ngay sau ten file .bat:

    CHAY_WEB.bat --cong 8080      Neu cong 8000 dang bi chuong trinh
                                  khac chiem ("Address already in use").
    CHAY_WEB.bat --cpu            Ep chay bang CPU, bo qua GPU.
                                  Cham hon nhieu nhung LUON dung.

6. NEU MAY BAN KHONG CO GPU, HOAC GPU QUA CU
-----------------------------------------------------------------------

Web van chay. Truoc khi chay, no tu thu that mot phep tinh nho tren
GPU. Neu GPU khong lam duoc (thuong gap o GTX 10xx tro xuong — kien
truc Pascal), web tu chuyen sang CPU va in mot dong canh bao ro rang.

    - Ket qua VAN DUNG y nhu tren GPU. Chi la CHAM HON NHIEU: do
      thuc te tren may tac gia, mot anh 640x640 mat ~84 giay bang CPU
      so voi ~1,8 giay bang GPU. Web KHONG bi treo — cu de cho, dung
      tat giua chung.
    - Tat han dong canh bao do: CHAY_WEB.bat --cpu

Cac doi GPU da biet la chay tot: GTX 1650 (sm_75), RTX 20xx/30xx
(sm_86), RTX 40xx (sm_89 — khong co trong danh sach cua wheel nhung
van chay duoc nho tuong thich nguoc).
